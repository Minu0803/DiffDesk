# 가운데 병합 공간 개선 시안 — 2026-10-13

현재 `MERGE_LANE_WIDTH`는 64px이며 차이와 내용이 없는 화면에도 전체 높이의 공간을 예약한다. 부분 병합 제목을 유지하기 위한 헤더 셀도 같은 폭을 차지한다. 실제 제품 변경 전, 사용자에게 다음 세 가지 시안을 제시한다.

## 추천: 컴팩트 병합

차이가 있을 때 중앙 폭을 32px로 줄이고 방향 버튼을 세로로 배치한다. 가운데 제목은 제거하고 방향·대상·줄 범위를 툴팁과 접근성 이름으로 제공한다. 빈 화면이나 차이가 없을 때에는 2px 구분선으로 접는다. 병합 영역은 차이가 있을 때 50%, 없을 때 약 97% 줄어든다. 이 수치는 다른 앱의 실측값이 아닌 DiffDesk 제안값이다.

촘촘한 한 줄 차이에서는 두 버튼을 무리하게 겹치지 않도록 현재 차이의 버튼과 차이 탐색을 우선 표시하고, 양방향 명령을 키보드와 메뉴에서도 제공해야 한다. 긴 차이와 화면 밖으로 일부 잘린 차이의 위치 추적, Undo, 가변 분할선 정렬은 유지한다. 넓은 클릭 영역이 필요한 터치 입력에서는 폭과 버튼을 키운다.

## 대안: 편집기 가장자리

중앙을 2px 구분선으로 줄이고 양쪽 편집기의 여백에 방향 버튼을 나눠 둔다. 중앙의 큰 세로 기둥을 없애는 효과가 가장 명확하다. 다만 버튼 여백은 편집기 안에서 필요하며 줄 번호·코드와 충돌하지 않게 예약해야 한다. 중앙 폭을 줄이는 것이 전부 코드 폭의 증가로 이어지지는 않는다.

## 대안: 상단 선택 병합

중앙을 2px로 유지하고 선택한 차이에 상단의 `왼쪽 적용`·`오른쪽 적용` 버튼을 사용한다. 코드 공간과 시각적 단순함에 유리하지만 차이 선택 후 포인터를 상단으로 옮기는 단계가 추가된다. 차이가 없는 상태에서는 명령을 비활성화한다.

## 참고한 공식 자료

- [Beyond Compare Text Compare](https://www.scootersoftware.com/home/multifaceted): 차이 옆 gutter 버튼과 단축키로 코드 구간을 복사한다.
- [JetBrains Rider Diff Viewer](https://www.jetbrains.com/help/rider/Differences_Viewer.html): 방향 버튼으로 차이를 적용하고 Undo·Redo 및 문맥 메뉴를 제공한다.
- [WinMerge File Compare](https://manual.winmerge.org/en/Compare_files.html): 선택한 차이에 따라 툴바·메뉴·단축키의 병합 명령을 활성화한다.

동작과 배치를 참고했으며 외부 테마 이름이나 팔레트는 가져오지 않았다. 시안은 자체 블랙 팔레트를 사용한다. 인터랙티브 비교에는 세 개선안과 현재 화면, 차이·빈 화면·동일 문서 상태를 포함했다. 시안의 방향 버튼은 예시 내용을 실제로 바꾸고 병합 취소로 되돌린다.
