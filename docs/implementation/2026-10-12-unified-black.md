## 검증

- 자동 테스트 19/19 및 renderer·Electron 타입 검사 통과. 이전 먹색 설정의 읽기·저장·재시작, 기본 블랙 선택과 Monaco 이름, 다른 설정 보존을 검사했다.
- 실제 Electron을 이전 먹색 설정으로 시작해 테마 메뉴의 기본 블랙 항목이 1개이며 선택된 값이 `dark`인지 확인했다. 먹색 항목은 0개다. 선택·입력·실행 취소, 문서 비우기·재열기, 파일 드롭·분할선 정렬도 통과했다.
- renderer·Electron 빌드 및 Windows x64 ZIP·portable·NSIS 빌드 통과.
- 새 셋업과 ZIP을 각각 검사하고 앱 파일 76개와 ASAR의 현재 빌드 파일 101개가 일치하는 것을 확인했다. 불일치와 앱 QA 스크립트는 0개다. Electron·Chromium·Monaco·React·ReactDOM 라이선스도 원본과 일치한다.
